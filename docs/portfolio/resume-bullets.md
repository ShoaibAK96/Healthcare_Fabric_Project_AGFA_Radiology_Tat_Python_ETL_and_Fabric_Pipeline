# Résumé Bullet Variant

- Designed an end-to-end healthcare data platform using Python, Oracle, Microsoft Fabric Pipelines, PySpark and Delta Lake, supporting independent daily TAT, manual recovery, historical staging and addendum workloads.
- Implemented secure extraction, atomic Excel publication, schema and business-date validation, SHA-256 lineage, corrected-date replacement, duplicate-safe loading, structured audit/error logging and multi-environment archiving.
- Streamed and validated a high-volume, multi-year historical dataset in controlled batches, using record-level hashing and date reconciliation to verify completeness and quality.
